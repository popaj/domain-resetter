How clearing works:
· Cookies, IndexedDB: Cleared globally for the domain chain (e.g., example.com also clears www.example.com).
· HTTP Cache: Cleared globally.
· Service Workers: Cleared globally (via Firefox's browsingData).
· Cache Storage & SessionStorage: Cleared per-site in the active tab (via Web APIs, not Firefox's browsingData API).
